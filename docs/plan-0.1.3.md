작성 2026-10-25. 이어서 하기 전에 `git log --oneline -15`와 `AGENTS.md`의 「남은 일」 0.1.3 줄을 먼저 본다.

## 다음 대화에서 할 것 (2026-10-25 정리)

0.1.3은 **스토어 심사 중**이다 (2026-10-25 제출). 큐 1~4는 모두 끝났다. 심사 중에는 스토어 항목을 고치지 않는다.

1. **사용자에게 먼저 알린다:** 0.1.3 심사 결과(메일)를 받았는지 묻는다. 통과했다면 게시됐는지 확인한다. 거절됐다면 사유를 받는다.
2. **다음 작업 (사용자 동의함, 「다음에 하자」): Claude API로 정부24 서류 안내 주소(`url`) 모으기**
   - 시작 전에 정할 것: 공식 SDK `@anthropic-ai/sdk`를 개발용 의존성으로 넣어도 되는지. 지침서상 새 라이브러리는 사용자에게 먼저 묻는다.
   - 방식:
     - 이 컴퓨터에서 도는 스크립트로 한다. 키는 `~/.zshrc`의 `ClaudeAPI=` 줄을 읽어 그 명령에만 `ANTHROPIC_API_KEY`로 넘긴다. 전역 export는 하지 않는다.
     - 정부24 공식 페이지에서 서류별 민원안내 주소 후보를 정리한다.
     - **사람이 열어 확인한 주소만** `catalog.js`의 `url`에 넣는다.
     - 서버만 다시 올리면 된다. 그 뒤로는 0.1.3의 「바로 가기」 단추가 보인다.
   - 모델은 기본값 `claude-opus-5-5`를 쓴다. 사용자가 다른 모델을 고르면 그것을 쓴다.
3. **사용자 확인을 기다리는 것 (아래 「남은 일」 2·3):**
   - 사업자등록 서류의 발급 사이트(운영 중인 `wrong_site` 위험)
   - 홈택스 버튼 목록(원인 B)
   - 작업 취향을 `AGENTS.md`로 옮길지
4. 그 밖의 Claude API 활용(민원 목록 늘리기, 시험 자료, 실제 사용 중 두 번째 의견)은 아래 「나중에」에 있다.

## 남은 일

### 1. 큐 4 — 0.1.3 제출 준비 (Vercel은 위임받음) — **처리방침 배포 완료 (2026-10-25, 실제 페이지와 원본이 같음 확인). 0.1.3 제출함 (2026-10-25, 심사 중 — 항목 고치지 않기)**

1. **처리방침 배포:** `store/privacy/index.html`을 기존 Vercel 프로젝트 `ldry-scrtry-privacy`에 올린다.
   - 이 컴퓨터에서는 연결이 이미 돼 있다. 연결 정보 `.vercel/`은 git에 안 들어간다.
   - 다른 컴퓨터에서는 `vercel whoami`로 로그인을 확인하고 기존 프로젝트에 다시 연결한다. 새 프로젝트를 만들지 않는다.
   - 올린 뒤 https://ldry-scrtry-privacy.vercel.app/ 에서 §4(화면 정보를 이 컴퓨터에 잠깐 둠)가 새 내용으로 바뀌었는지 확인한다.
2. **사용자에게 제출을 안내한다:**
   - `ldry-scrtry.zip` (`npm run package`, 태그 `v0.1.3`)
   - 개인정보 탭의 `storage` 사유를 `store/LISTING.md` §3-1 새 문구로 바꾼다.
   - 심사 중에는 항목을 고치지 않는다.
   - **제출은 사용자가 직접 한다.**
3. **`v0.1.3` 태그는 이미 push했으니 옮기지 않는다.** 제출 전에 확장 코드를 더 고치면 **0.1.4**로 올려서 낸다. 스토어는 0.1.2보다 높으면 받는다.

### 2. 자료 빈틈 (위험, 이미 운영 중)

- 「사업자등록증 재발급」·「사업자등록증명」은 `catalog.js`에 `site`가 없다.
- 그래서 정부24가 「사이트가기」·「바로가기」가 아닌 다른 이름의 버튼으로 홈택스에 보내면, `wrong_site` 규칙이 그 사람에게 "정부24로 가세요"라고 안내할 수 있다.
- **사용자에게 「사이트가기」가 어디로 가는지 확인받은 뒤** `site: 'www.hometax.go.kr'`을 넣고 서버만 다시 올린다. 심사는 필요 없다.

### 3. 사용자에게 받을 것

1. **홈택스 메인 화면의 버튼 목록**(「마지막 화면 정보 복사하기」 또는 콘솔 한 줄). 검색 칸이 후보에서 아예 빠졌는지(원인 B) 판단한다. 원인 B라면 `content.js` 후보 수집을 고친다. 확장 코드가 바뀌므로 0.1.4가 된다.
2. 위 2의 사업자등록 서류 발급 사이트.
3. 작업 취향(선택 팝업 대신 글로 묻기)을 `AGENTS.md`로 옮길지.
