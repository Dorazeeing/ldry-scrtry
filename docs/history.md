- 글에 나오는 경로는 그때 기준이다: `slop-detector/` → 지금 `reference/slop-detector/`, `docs/` → 지금 `docs/`(같음), 확장 폴더 → 지금 저장소 루트.

### 52. 로그인은 사용자가 직접
> [화면 캡처] 다음과 같이 진행하자.
> 지금 시도해보니까 로그인을 먼저 유도하도록 작동했어. 그러지말고, 무조건 해당 공문서를 먼저 찾아가게해.

**결과:** 로그인·회원가입 버튼은 안내 대상에서 제외하고 서류 페이지로 먼저 안내. 로그인 방법·회원/비회원 선택 화면에서는 테두리를 끄고 "여기서부터는 직접 골라 주세요" 안내.
